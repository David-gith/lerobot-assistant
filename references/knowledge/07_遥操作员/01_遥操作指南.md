# 遥操作指南

> **文档地址**：https://huggingface.co/docs/lerobot/v0.5.1/en/il_robots#teleoperate

---

## 概述

遥操作 (Teleoperation) 是通过 Leader 设备控制 Follower 机器人进行数据收集的过程。LeRobot 支持多种遥操作方式。

---

## 命令行遥操作

### 基本命令

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_robot \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_leader
```

### 带显示的遥操作

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_robot \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_leader \
    --display_data=true
```

### 带相机的遥操作

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_robot \
    --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 1920, height: 1080, fps: 30}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_leader \
    --display_data=true
```

## Python API

```python
from lerobot.scripts.control_robot import teleoperate

teleoperate(
    robot_type="so101_follower",
    robot_port="/dev/ttyUSB0",
    robot_id="my_robot",
    teleop_type="so101_leader",
    teleop_port="/dev/ttyUSB1",
    teleop_id="my_leader",
    display_data=True,
)
```

---

## 键盘遥操作

```python
from lerobot.scripts.control_robot import teleoperate_with_keyboard

teleoperate_with_keyboard(
    robot_type="so101_follower",
    robot_port="/dev/ttyUSB0",
    robot_id="my_robot",
)
```

---

## 控制参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--control.fps` | 控制频率 | 30 |
| `--control.display_data` | 显示实时数据 | false |
| `--calibration.resume` | 恢复校准 | false |

---

## 退出遥操作

- 按 `Q` 键退出
- 按 `Ctrl+C` 强制退出
