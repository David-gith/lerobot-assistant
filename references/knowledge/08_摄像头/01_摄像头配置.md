# 摄像头配置

> 来源：LeRobot v0.5.1 Cameras  
> https://huggingface.co/docs/lerobot/cameras

## 适用场景

用户要给机器人添加 USB/RealSense/OpenCV 相机，或录制时相机无画面。

## 配置示例

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyUSB0 \
  --robot.id=my_so101 \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --display_data=true
```

## 排查

- 找不到相机：检查 `/dev/video*`、权限和占用进程。
- 黑屏：检查 index、分辨率、曝光和 USB 带宽。
- FPS 不稳定：降低分辨率或减少相机数量。
- 多相机不同步：先确认每路相机能单独稳定采集。
