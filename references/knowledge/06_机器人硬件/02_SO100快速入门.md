# SO-100 快速入门

> 来源：LeRobot v0.5.1 SO-100  
> https://huggingface.co/docs/lerobot/so100

## 适用场景

用户使用 SO-100 机械臂进行校准、遥操作或数据采集。

## 要点

- SO-100/SO-101/Moss 相关电机通常需要 Feetech SDK。
- 先检查 USB 端口和权限，再运行校准。
- robot id 会关联校准文件，同一套硬件应保持 id 一致。

## 常用安装

```bash
pip install "lerobot[feetech]==0.5.1"
```
