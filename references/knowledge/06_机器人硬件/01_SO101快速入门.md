# SO-101 快速入门

> **机器人类型**：SO-101 机械臂
> **适用场景**：桌面操作、物体抓取、精细操作
> **SDK**：Feetech
> **文档地址**：https://huggingface.co/docs/lerobot/v0.5.1/en/so101

---

## 硬件规格

| 参数 | 值 |
|------|-----|
| 自由度 | 6 DOF (每臂) |
| 通信接口 | USB 串口 |
| 控制频率 | 30 Hz |
| 电源 | 12V DC |
| 校准方式 | 关节限位法 |

---

## 安装步骤

### Step 1: 安装 LeRobot 和 Feetech SDK

```bash
# 从源码安装（推荐开发版）
git clone https://github.com/huggingface/lerobot.git
cd lerobot
pip install -e ".[feetech]"

# 或稳定版安装
pip install lerobot==0.5.1[feetech]
```

### Step 2: 组装机器人

按照官方 README 中的物料清单（BOM）和 3D 打印说明进行组装。

### Step 3: 连接 USB

1. 使用 USB-C 线连接 Follower（执行器）和计算机
2. 使用 USB-C 线连接 Leader（遥操作器）和计算机

### Step 4: 查找端口

```bash
# Linux
ls -l /dev/ttyUSB*
# 输出示例: /dev/ttyUSB0, /dev/ttyUSB1

# macOS
ls -l /dev/tty.usbmodem*
# 输出示例: /dev/tty.usbmodem58760431541
```

## 校准

### 校准 Follower（执行器）

```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm
```

### 校准 Leader（遥操作器）

```bash
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm
```

### 校准流程说明

1. 首先将机器人移动到所有关节都在中间位置的位置
2. 按 Enter 开始
3. 依次移动每个关节通过其完整运动范围
4. 完成后自动保存校准文件

> **重要**：`id` 用于存储校准文件。在遥操作、录制和评估时使用相同的 `id`。

### 校准文件位置

`~/.cache/huggingface/lerobot/calibration/{robot_id}/`

## 遥操作

### 基本遥操作

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm
```

### 遥操作并显示数据

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm \
    --display_data=true
```

### 带相机的遥操作

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 1920, height: 1080, fps: 30}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm \
    --display_data=true
```

## 录制数据集

```bash
lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm \
    --fps 30 \
    --repo-id ${HF_USER}/so101_tutorial \
    --tags tutorial \
    --warmup-time-s 5 \
    --episode-time-s 60 \
    --reset-time-s 30 \
    --num-episodes 50
```

## 训练和评估

### 训练 ACT 策略

```bash
lerobot train \
    --repo-id ${HF_USER}/so101_tutorial \
    --policy.type=act \
    --device=cuda
```

### 评估

```bash
lerobot evaluate \
    --repo-id ${HF_USER}/so101_tutorial \
    --checkpoint=outputs/train/act/checkpoints/latest \
    --device=cuda
```

## 故障排查

### 问题：Permission denied: /dev/ttyUSB0

**解决**：
```bash
# 添加用户到 dialout 组
sudo usermod -a -G dialout $USER
# 重新登录使生效
```

### 问题：无法找到端口

**解决**：
```bash
# 检查 USB 设备
lsusb

# 查看内核日志
dmesg | tail

# 尝试其他端口
ls /dev/ttyUSB*
```

### 问题：校准后跟随不准确

**解决**：
1. 重新校准（确保移动完整范围）
2. 检查 USB 连接稳定性
3. 降低控制频率试试
