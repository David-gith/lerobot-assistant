# 机器人的模仿学习

> **教程级别**：入门
> **预计时间**：30 分钟
> **前置要求**：LeRobot 已安装，机器人已连接和校准
> **文档地址**：https://huggingface.co/docs/lerobot/v0.5.1/en/il_robots

本教程将教你如何训练一个神经网络来自主控制真实机器人。你将学习：

1. 如何录制和可视化数据集
2. 如何使用数据训练策略并准备评估
3. 如何评估策略并可视化结果

---

## 工作流程概览

```
遥操作录制数据 → 数据集上传 Hub → 策略训练 → 策略评估
     ↓                ↓              ↓           ↓
lerobot-teleoperate  lerobot-record  lerobot-train  lerobot-evaluate
```

## Step 2: 遥操作

本示例演示如何遥操作 SO-101 机器人。

### 命令行方式

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm
```

### Python API 方式

```python
from lerobot.scripts.control_robot import teleoperate

teleoperate(
    robot_type="so101_follower",
    robot_port="/dev/ttyUSB0",
    robot_id="my_awesome_follower_arm",
    teleop_type="so101_leader",
    teleop_port="/dev/ttyUSB1",
    teleop_id="my_awesome_leader_arm",
)
```

> **注意**：`id` 用于存储校准文件。在使用同一设置时，在遥操作、录制和评估中保持使用相同的 `id`。

### 遥操作命令会自动：

1. 将 Leader 和 Follower 对齐
2. 检测相机并启动显示
3. 启用键盘控制（按 `Q` 退出）

### 添加相机

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 1920, height: 1080, fps: 30}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm \
    --display_data=true
```

### 使用 Rerun 可视化

```bash
lerobot-teleoperate \
    --robot.type=koch_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_koch \
    --robot.cameras="{top: {type: opencv, index_or_path: 0}}" \
    --teleop.type=koch_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_koch_leader \
    --display_data=true
```

## Step 3: 录制数据集

熟悉遥操作后，可以录制第一个数据集。

LeRobot 使用 Hugging Face Hub 功能上传数据集。如果之前未使用过 Hub，确保可以通过 CLI 登录并使用写访问 Token（可从 HF 设置生成）。

### 基本录制命令

```bash
lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_awesome_follower_arm \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_awesome_leader_arm \
    --fps 30 \
    --repo-id ${HF_USER}/koch_test \
    --tags tutorial \
    --warmup-time-s 5 \
    --episode-time-s 30 \
    --reset-time-s 30 \
    --num-episodes 2
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--fps` | 帧率 | 30 |
| `--warmup-time-s` | 预热时间（秒） | 5 |
| `--episode-time-s` | 每个 episode 的时长 | 60 |
| `--reset-time-s` | 重置时间 | 30 |
| `--num-episodes` | 录制的 episode 数量 | 50 |
| `--tags` | Hugging Face 数据集标签 | - |
| `--dataset.push_to_hub` | 是否自动上传到 Hub | true |
| `--dataset.normalize_actions` | 是否归一化动作 | false |

### 数据存储位置

本地数据集存储在：`~/.cache/huggingface/lerobot/{repo-id}/`

例如：`~/.cache/huggingface/lerobot/{your_username}/koch_test/`

### 数据上传

录制结束时，数据集将自动上传到你的 Hugging Face 页面。查看你的用户名：

```bash
echo ${HF_USER}
```

你的数据集将自动标记 `LeRobot` 标签，方便社区查找。

### 手动上传

```bash
python -c "
from lerobot import LeRobotDataset
ds = LeRobotDataset.from_repo_id('${HF_USER}/koch_test')
ds.push_to_hub('${HF_USER}/koch_test')
"
```

### 断点续录

如果录制中断，可以恢复：

```bash
lerobot-record \
    # ... 相同参数 ...
    --control.resume=true \
    --dataset.num_episodes=10  # 注意：这是要新增的 episode 数量
```

> **注意**：恢复录制时，`--dataset.num_episodes` 是要新增的 episode 数量，而非目标总数！

### 本地录制（不上传）

```bash
lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyUSB0 \
    --robot.id=my_robot \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyUSB1 \
    --teleop.id=my_leader \
    --fps 30 \
    --repo-id ${HF_USER}/my_local_dataset \
    --dataset.push_to_hub=false  # 不上传
```

## Step 4: 训练策略

### 训练 ACT 策略

```bash
lerobot train \
    --repo-id ${HF_USER}/koch_test \
    --policy.type=act \
    --device=cuda  # Linux GPU
    # 或 --device=mps  # macOS Apple Silicon
    # 或 --device=cpu  # 无 GPU
```

### 使用预训练检查点微调

```bash
lerobot train \
    --repo-id ${HF_USER}/koch_test \
    --policy.type=act \
    --checkpoint=lerobot/act_koch_real \
    --device=cuda
```

### 指定训练参数

```bash
lerobot train \
    --repo-id ${HF_USER}/koch_test \
    --policy.type=act \
    --policy.lr=1e-4 \
    --policy.batch_size=8 \
    --training.num_workers=4 \
    --device=cuda
```

### 训练输出位置

训练输出位于：`outputs/train/{policy_type}/`

包含：
- `checkpoints/` — 模型检查点
- `train.log` — 训练日志
- `val.log` — 验证日志
- `config.json` — 配置快照

## Step 5: 评估策略

### 基本评估

```bash
lerobot evaluate \
    --repo-id ${HF_USER}/koch_test \
    --checkpoint=outputs/train/act/checkpoints/latest \
    --device=cuda
```

### 使用预训练模型评估

```bash
lerobot evaluate \
    --repo-id lerobot/smolvla_vlabench \
    --device=cuda
```

### 使用 Rerun 可视化

```bash
rerun outputs/train/act/eval
```

## 录制函数详解

### 1. 数据存储

数据使用 `LeRobotDataset` 格式存储在磁盘上。默认情况下，录制后上传到 Hugging Face 页面。使用 `--dataset.push_to_hub=False` 禁用上传。

### 2. 检查点和恢复

录制期间自动创建检查点。如果出现问题，可以通过添加 `--control.resume=true` 重新运行相同命令来恢复。

### 3. 录制参数

| 参数 | 说明 |
|------|------|
| `--dataset.episode_time_s=60` | 每个 episode 60 秒 |
| `--dataset.reset_time_s=60` | 重置时间 60 秒 |
| `--dataset.num_episodes=50` | 录制 50 个 episode |
| `--dataset.delta_timestamps_between_images=0.1` | 图像之间的时间戳 |

## 常见问题

### Q: 录制时画面卡顿？

检查：
1. 相机帧率是否过高（降低 `--fps`）
2. USB 带宽是否足够（尝试降低分辨率）
3. 磁盘写入速度是否足够（SSD 推荐）

### Q: 数据集上传失败？

1. 检查网络连接
2. 确保已登录：`huggingface-cli login`
3. 检查 Token 权限

### Q: 如何从零开始录制新数据集？

删除本地目录后重新录制：
```bash
rm -rf ~/.cache/huggingface/lerobot/{user}/{repo_id}
```
