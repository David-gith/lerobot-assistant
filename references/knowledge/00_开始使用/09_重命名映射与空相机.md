# Rename Map 与空相机

> 来源：LeRobot v0.5.1 Using Rename Map and Empty Cameras  
> https://huggingface.co/docs/lerobot/rename_map_empty_cameras

## 适用场景

用户的数据集字段名、相机名或 observation/action 名称与策略期望不一致。

## 核心用途

- rename map 用于把旧字段映射到新字段。
- 空相机处理用于兼容缺失相机或不同机器人采集的数据。
- 迁移大型数据集或复用预训练策略时尤其常见。

## 排查步骤

1. 打印数据集 features，确认真实字段名。
2. 对照 policy 需要的 input/output features。
3. 设置 rename map 或补齐空相机占位。
4. 重新计算数据集统计量后再训练。
