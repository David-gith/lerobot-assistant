# LeRobot 安装指南

> **当前版本**：v0.5.1（稳定版）
> **文档地址**：https://huggingface.co/docs/lerobot/v0.5.1/en/installation

---

## 安装方式对比

| 方式 | 命令 | 适用场景 |
|------|------|----------|
| **稳定版 (v0.5.1)** | `pip install lerobot==0.5.1` | 生产环境、快速体验 |
| **开发版 (源码)** | `pip install -e ".[extras]"` | 需要最新功能、贡献代码 |
| **PyPI 最新** | `pip install lerobot` | 尝鲜最新版 |

---

## 方式一：稳定版安装（推荐）

```bash
# 创建环境（可选，但推荐）
conda create -n lerobot python=3.12 -y
conda activate lerobot

# 安装稳定版 v0.5.1
pip install lerobot==0.5.1

# 验证安装
python -c "import lerobot; print(lerobot.__version__)"
# 输出: 0.5.1
```

### 稳定版包含的 extras

```bash
# 仿真环境
pip install lerobot==0.5.1  # 默认不包含仿真
pip install lerobot==0.5.1[aloha,pusht]  # 包含仿真

# 硬件支持
pip install lerobot==0.5.1[feetech]   # SO-101/SO-100/Moss
pip install lerobot==0.5.1[dynamixel] # Koch v1.1

# 组合安装
pip install lerobot==0.5.1[aloha,pusht,feetech]
```

## 方式二：从源码安装（开发版）

### Step 1: 安装 miniforge（推荐环境管理器）

```bash
# 下载并安装 miniforge
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh

# 激活 base 环境
source ~/miniforge3/bin/activate
```

### Step 2: 创建 Python 环境

```bash
conda create -y -n lerobot python=3.12
conda activate lerobot
```

> **Python 要求**：>= 3.12，< 3.13（开发版需要 PyTorch >= 2.10）

### Step 3: 克隆仓库并安装

```bash
# 克隆源码
git clone https://github.com/huggingface/lerobot.git
cd lerobot

# 安装基础包
pip install -e .

# 安装可选依赖（根据需求选择）
pip install -e ".[aloha,pusht]"           # 仿真环境
pip install -e ".[feetech]"               # SO-101/SO-100 硬件
pip install -e ".[dynamixel]"            # Koch 硬件
pip install -e ".[aloha,pusht,feetech]" # 全量安装

# 或使用 uv
uv pip install -e ".[aloha,pusht,feetech]"
```

### Step 4: 安装 ffmpeg（Linux 必须）

```bash
# 使用 conda 安装（推荐）
conda install -c conda-forge ffmpeg

# 或使用系统包管理器
sudo apt install ffmpeg  # Ubuntu/Debian
brew install ffmpeg       # macOS
```

> **注意**：如果安装 ffmpeg 后 OpenCV 出现问题：
> ```bash
> pip uninstall opencv-python
> conda install -c conda-forge "opencv>=4.10.0"
> ```

### Step 5: 验证安装

```bash
# 检查版本
python -c "import lerobot; print(lerobot.__version__)"

# 检查 CLI 命令
lerobot --help

# 检查可用的子命令
# 应显示: teleoperate, record, train, evaluate
```

## WSL2 安装注意事项

在 Windows WSL2 中安装时，需要额外安装 `evdev`：

```bash
conda install evdev -c conda-forge
```

## 依赖说明

### 核心依赖

- Python >= 3.12
- PyTorch >= 2.10
- huggingface_hub
- gymnasium
- safetensors

### 可选依赖

| Extra | 包含内容 | 使用场景 |
|-------|----------|----------|
| `aloha` | gym-aloha, dm-control | Aloha 仿真 |
| `pusht` | gym-pusht, dm-control | PushT 仿真 |
| `feetech` | feetech_servo_sdk | SO-101/SO-100/Moss |
| `dynamixel` | dynamixel-sdk | Koch v1.1 |
| `wandb` | wandb | 实验追踪 |
| `dev` | 测试/开发工具 | 贡献代码 |

### 系统依赖

| 系统 | 依赖 | 安装命令 |
|------|------|----------|
| Linux | cmake, build-essential | `sudo apt install cmake build-essential` |
| Linux | ffmpeg libs | `sudo apt install libavformat-dev libavcodec-dev ...` |
| macOS | ffmpeg | `brew install ffmpeg` |

## 故障排查

### 问题：ModuleNotFoundError: No module named 'lerobot'

**原因**：未正确安装或未激活环境

**解决**：
```bash
# 检查是否在正确的环境中
which python
python -c "import sys; print(sys.path)"

# 重新安装
pip install -e .
```

### 问题：PyTorch 版本不兼容

**解决**：
```bash
# 升级 PyTorch
pip install torch>=2.10 torchvision --upgrade

# 或使用 conda
conda install pytorch>=2.10 pytorch torchvision -c pytorch
```

### 问题：ffmpeg 相关错误

**解决**：
```bash
# Linux: 检查 ffmpeg 是否可用
ffmpeg -version

# 如果不可用，重新安装
conda install -c conda-forge ffmpeg

# 或编译安装 PyAV（高级用户）
# 见 https://huggingface.co/docs/lerobot/v0.5.1/en/installation#troubleshooting
```
