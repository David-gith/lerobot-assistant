# LeRobot FAQ 故障排查

> **涵盖**：安装、运行、训练过程中的常见问题

---

## 安装问题

### 问题：pip install lerobot 失败

**原因**：网络问题或依赖冲突

**解决**：
```bash
# 使用国内镜像
pip install lerobot -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或使用 conda
conda install -c conda-forge lerobot
```

### 问题：Python 版本不兼容

**原因**：Python < 3.12

**解决**：
```bash
conda create -n lerobot python=3.12 -y
conda activate lerobot
```

### 问题：PyTorch 版本不匹配

**原因**：需要 PyTorch >= 2.10

**解决**：
```bash
pip install "torch>=2.10" torchvision --upgrade
```

## 环境问题

### 问题：ModuleNotFoundError: No module named 'lerobot'

**解决**：
```bash
# 检查安装
pip show lerobot

# 重新安装
pip install -e .
```

### 问题：CUDA out of memory

**解决**：
1. 减小 batch_size
2. 减小图像分辨率
3. 使用更小的模型

```bash
# 示例
lerobot-train \
    --dataset.repo_id USER/dataset \
    --policy.batch_size=2 \
    --device=cuda
```

## 硬件问题

### 问题：Permission denied: /dev/ttyUSB0

**解决**：
```bash
# 添加用户到 dialout 组
sudo usermod -a -G dialout $USER
# 重新登录
```

### 问题：找不到 USB 端口

**解决**：
```bash
# Linux
ls -l /dev/ttyUSB*
dmesg | tail

# macOS
ls -l /dev/tty.usbmodem*
```

### 问题：校准后跟随不准确

**解决**：
1. 重新校准，确保移动完整范围
2. 检查 USB 连接稳定性
3. 降低控制频率

---

## 训练问题

### 问题：训练 loss 不下降

**检查**：
1. 数据集是否正确加载
2. 动作维度是否匹配
3. 学习率是否过大/过小

### 问题：数据集加载很慢

**解决**：
1. 使用 SSD 存储本地缓存
2. 增加 num_workers
3. 预加载到内存

---

## 数据集问题

### 问题：上传到 HF Hub 失败

**解决**：
```bash
# 检查登录状态
huggingface-cli login

# 检查 Token 权限
huggingface-cli whoami
```

### 问题：录制视频不完整

**解决**：
1. 检查磁盘空间
2. 检查 ffmpeg 安装
3. 检查 USB 带宽

---

## 推理问题

### 问题：推理速度太慢

**解决**：
1. 使用 GPU
2. 减小图像分辨率
3. 使用更小的模型

### 问题：动作抖动

**解决**：
1. 增加 chunk_size
2. 检查动作归一化
3. 减小控制频率
