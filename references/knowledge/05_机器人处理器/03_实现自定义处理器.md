# 实现自定义处理器

> 来源：LeRobot v0.5.1 Implement your own processor  
> https://huggingface.co/docs/lerobot/implement_processor

## 适用场景

用户需要自定义图像预处理、动作后处理、传感器融合或字段转换。

## 建议

- 保持 processor 输入输出字段命名清晰。
- 避免在 processor 中引入不可复现的随机逻辑。
- 写单元测试覆盖单样本和 batch。
- 对真机 action processor 加安全限幅。

## 排查

- 训练和推理不一致：确认两边使用同一 processor 配置。
- 速度慢：避免在控制循环里做重 IO 或昂贵转换。
