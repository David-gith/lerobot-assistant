# 机器人与遥操作处理器

> 来源：LeRobot v0.5.1 Processors for Robots and Teleoperators  
> https://huggingface.co/docs/lerobot/robot_processors

## 适用场景

用户要在 robot 或 teleoperator 端处理 observation/action，例如缩放、滤波、字段转换。

## 建议

- robot processor 关注真实硬件输入输出。
- teleoperator processor 关注人类控制器到机器人动作的映射。
- 真机动作处理应加入速度、角度和 gripper 限制。

## 排查

- 遥操作方向反了：检查 teleop 到 robot action 的映射。
- 校准后仍不准：确认 processor 没有再次缩放错误。
- 采集字段异常：检查 processor 是否修改了 key。

（来源：Processors for Robots and Teleoperators）
