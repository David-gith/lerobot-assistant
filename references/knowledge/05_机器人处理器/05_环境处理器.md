# 环境处理器

> 来源：LeRobot v0.5.1 Environment Processors  
> https://huggingface.co/docs/lerobot/environment_processors

## 适用场景

用户在仿真环境或 benchmark 中处理 observation/action/reward。

## 建议

- 明确环境原始 observation 与策略输入的映射。
- 将 reward 和 done 的转换逻辑写清楚。
- 保证训练和评估使用一致配置。

## 排查

- 训练能跑但效果差：检查 reward processor。
- action 越界：检查反归一化和环境 action space。
