## 什么是处理器 (Processor)

处理器是 LeRobot 中用于数据转换和标准化的核心组件，解决了机器人和人类产生的数据与机器学习模型期望格式之间的根本不匹配问题。

**处理器解决的问题**：
- 机器人输出的原始传感器数据（图像、关节位置）需要标准化
- 语言指令需要转换为数值表示（tokenization）
- 不同机器人使用不同的坐标系需要统一
- 数据需要在正确的设备上（CPU/GPU）进行正确的批处理

---

## 处理器架构

### 核心概念：Transition

`Transition` 是处理器中的核心数据结构，包含观察、动作和元数据：

```python
from lerobot.common.datasets.sequences import Transition

# Transition 结构
{
    "observation": {
        "images": {"camera_name": torch.Tensor},  # 图像
        "state": torch.Tensor,                      # 关节状态
    },
    "action": torch.Tensor,                         # 动作
    "frame_index": int,                             # 帧索引
    "timestamp": float,                             # 时间戳
}
```

### 处理流程

```
原始数据 → RobotProcessor → Transition → PolicyProcessor → Batch → Model
                          ↓
                   环境格式化
```

## 处理器分类

### 1. 机器人硬件处理器 (Robot Hardware Converters)

| 函数 | 输入 | 输出 |
|------|------|------|
| `robot_action_to_transition` | Robot dict | EnvTransition |
| `observation_to_transition` | Robot obs | EnvTransition |
| `transition_to_robot_action` | EnvTransition | Robot dict |

### 2. 策略/训练处理器 (Policy/Training Converters)

| 函数 | 输入 | 输出 |
|------|------|------|
| `batch_to_transition` | Batch dict | EnvTransition |
| `transition_to_batch` | EnvTransition | Batch dict |
| `policy_action_to_transition` | Policy tensor | EnvTransition |
| `transition_to_policy_action` | EnvTransition | Policy tensor |

### 3. 工具函数 (Utilities)

| 函数 | 说明 |
|------|------|
| `create_transition` | 创建带有默认值的 transition |
| `identity_transition` | 直通转换器 |

## 常用处理器

### 归一化处理器

```python
from lerobot.common.processors import normalizer_processor

# 使用数据集统计信息归一化
normalizer_processor(
    stats={"mean": ..., "std": ...},
    keys=["observation.state", "action"],
)
```

### 设备处理器

```python
from lerobot.common.processors import device_processor

# 移动到 GPU
device_processor(
    device="cuda",
    keys=["observation.images", "action"],
)
```

### 批处理处理器

```python
from lerobot.common.processors import to_batch_processor

# 添加批次维度
to_batch_processor(keys=["observation", "action"])
```

### 重命名处理器

```python
from lerobot.common.processors import rename_observations_processor

# 重命名观察键
rename_observations_processor(
    mapping={
        "camera/image": "observation.images.front",
        "joint_positions": "observation.state",
    }
)
```

### 分词处理器

```python
from lerobot.common.processors import tokenizer_processor

# Tokenize 语言指令
tokenizer_processor(
    tokenizer="t5-base",
    task_key="task",
)
```

## 自定义处理器

### 创建自定义处理器

```python
from lerobot.common.processors import register_processor

@register_processor("my_custom_processor")
def my_custom_processor(data, config):
    """
    自定义处理器逻辑
    """
    # 处理数据
    processed = transform(data, config)

    # 返回处理后的数据
    return processed
```

### 在配置中使用

```python
from lerobot.configs import RobotConfig

config = RobotConfig(
    cameras=["front", "wrist"],
    processors=[
        {
            "type": "normalizer_processor",
            "keys": ["observation.state"],
        },
        {
            "type": "device_processor",
            "device": "cuda",
        },
        {
            "type": "my_custom_processor",
            "param1": "value1",
        },
    ],
)
```

## 处理器管道

### 定义处理管道

```python
from lerobot.common.processors.pipeline import ProcessorPipeline

# 创建处理管道
pipeline = ProcessorPipeline([
    ("normalize_state", normalizer_processor(keys=["observation.state"])),
    ("normalize_action", normalizer_processor(keys=["action"])),
    ("to_batch", to_batch_processor()),
    ("to_device", device_processor(device="cuda")),
])
```

### 执行处理

```python
# 处理单个 transition
processed = pipeline(transform)

# 处理批次
batched = pipeline.batch_process([transform1, transform2, ...])
```

## 常见问题

### Q: 处理后数据形状不对？

**检查**：
1. batch dimension 是否正确
2. key 名称是否匹配
3. 数据类型是否一致

### Q: GPU 内存不足？

**解决**：
1. 减小图像分辨率
2. 延迟加载大图像
3. 使用 float16
