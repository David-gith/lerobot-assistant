# 动作表示

> 来源：LeRobot v0.5.1 Action Representations  
> https://huggingface.co/docs/lerobot/action_representations

## 适用场景

用户讨论绝对动作、相对动作、chunk、动作归一化或不同机器人动作空间迁移。

## 核心检查

- action 是关节角、末端位姿还是速度/增量。
- action 是否包含 gripper。
- 训练和推理的归一化方式是否一致。
- chunk size 与策略配置是否一致。

## 常见问题

- 动作幅度异常：检查 stats 和反归一化。
- gripper 行为错误：确认是否从相对动作中排除。
- 迁移到新机器人失败：检查 action 名称和维度。
