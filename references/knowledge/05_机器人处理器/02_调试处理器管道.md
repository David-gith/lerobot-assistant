# 调试处理器管道

> 来源：LeRobot v0.5.1 Debug your processor pipeline  
> https://huggingface.co/docs/lerobot/debug_processors

## 适用场景

用户的 observation/action 在 processor 前后维度、名称或数值范围异常。

## 调试方法

1. 打印 processor 输入输出 features。
2. 对单条样本逐步执行 processor。
3. 检查图像形状、dtype、归一化范围。
4. 检查 action 是否被裁剪、缩放或重命名。
5. 用小 batch 跑训练/推理 smoke test。

## 常见问题

- KeyError：字段名不匹配，用 rename map 或改 processor。
- Shape mismatch：检查相机通道顺序和 action 维度。
- 动作异常：检查反归一化和安全限幅。
