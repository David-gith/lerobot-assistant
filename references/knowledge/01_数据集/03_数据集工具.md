# 数据集工具

> 来源：LeRobot v0.5.1 Using the Dataset Tools  
> https://huggingface.co/docs/lerobot/using_dataset_tools

## 适用场景

用户要检查、可视化、编辑、合并或上传 LeRobotDataset。

## 常见任务

- 查看数据集 metadata 和 features。
- 可视化 episode、相机帧、状态和动作。
- 重算统计量。
- 删除错误 episode 或修复字段。
- 上传到 Hugging Face Hub。

## 排查思路

1. 先确认 `repo_id` 和本地缓存路径。
2. 检查数据集是否能被 `LeRobotDataset(repo_id)` 加载。
3. 对字段名、FPS、episode 数和 video 文件做一致性检查。
4. 修改数据后重算 stats，再训练。
