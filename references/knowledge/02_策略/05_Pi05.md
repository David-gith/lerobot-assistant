# Pi0.5 策略

> 来源：LeRobot v0.5.1 π₀.₅ (Pi05)  
> https://huggingface.co/docs/lerobot/pi05

## 定位

Pi0.5 属于 Pi 系列视觉-语言-动作策略，用于机器人任务微调和评估。

## 使用入口

```bash
lerobot-train \
  --dataset.repo_id=your_dataset \
  --policy.type=pi05 \
  --policy.device=cuda
```

## 建议

- 先确认数据集是否包含任务文本、图像和动作字段。
- 大模型训练优先使用 CUDA、混合精度和梯度检查点。
- 迁移已有策略时检查相机名、action 维度和数据集 stats。
