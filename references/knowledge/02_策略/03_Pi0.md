# Pi0 策略

> 来源：LeRobot v0.5.1 π₀ (Pi0)  
> https://huggingface.co/docs/lerobot/pi0

## 定位

Pi0 是视觉-语言-动作模型，面向通用机器人控制。LeRobot 中通过 `policy.type=pi0` 使用。

## 安装

```bash
pip install -e ".[pi]"
```

## 训练入口

```bash
lerobot-train \
  --dataset.repo_id=your_dataset \
  --policy.type=pi0 \
  --policy.pretrained_path=lerobot/pi0_base \
  --policy.device=cuda
```

## 常用优化

- `--policy.gradient_checkpointing=true`：降低显存。
- `--policy.dtype=bfloat16`：混合精度。
- `--policy.train_expert_only=true`：冻结部分 VLM，只训练动作专家相关模块。
- `--policy.use_relative_actions=true`：使用相对动作，需先重算数据集统计。

## 排查

- 显存不足：减小 batch size，启用梯度检查点或只训练 expert。
- 动作不稳定：检查动作归一化、相对动作设置和数据集统计。
