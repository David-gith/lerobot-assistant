# 向后兼容

> 来源：LeRobot v0.5.1 Backward compatibility  
> https://huggingface.co/docs/lerobot/backward_compatibility

## 适用场景

用户遇到旧数据集、旧 checkpoint、旧 CLI 参数或跨版本迁移问题。

## 排查

- 先确认 LeRobot 版本：`python -c "import lerobot; print(lerobot.__version__)"`
- 检查数据集格式版本和 features。
- 对旧字段使用 rename map 或迁移工具。
- 训练 checkpoint 不兼容时，优先使用同版本代码加载。

（来源：Backward compatibility）
